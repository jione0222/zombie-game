# 3D 탑다운 좀비 슈터 (Unity)

손그림 맵(`map_sketch.jpg`)을 그대로 옮긴 웨이브형 좀비 게임입니다. 에셋 없이 기본 도형만으로 바로 플레이할 수 있습니다.

## 설치
1. Unity Hub → **3D (URP 또는 Built-in)** 새 프로젝트 (Unity 2022.3 LTS 이상 / Unity 6 권장)
2. `Assets/Scripts` 폴더를 프로젝트의 `Assets` 안에 복사
3. Hierarchy 우클릭 → `Create Empty` → **GameBootstrap** 스크립트 붙이기
4. ▶ Play → 로비 화면에서 START (Enter로도 시작)
- 게임오버/승리 화면에서 RESTART 또는 LOBBY 선택

## 맵
```
 ┌(스폰)────────────────(스폰)┐
 │           윗방             │
 ├─────────────┐    ┌─────────┤   ← 가운데 벽, 문 하나
 │                            │
 │        아랫방 (시작 위치)  │
 └────────────────────────────┘
```
- 선 = 벽, 위쪽 두 모서리의 1/4 원 = 좀비 스폰 구역
- 좀비는 플레이어가 다른 방에 있으면 문으로 돌아서 옵니다
- 크기/문 위치는 `MapLayout.cs` 숫자만 바꾸면 수정됩니다

## 조작
| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 조준 |
| 좌클릭 / Space | 발사 (누르고 있으면 연사) |
| R | 재장전 (게임 끝나면 재시작) |
| 1~4 / Q | 무기 교체 |

## 수치
| 항목 | 값 |
|---|---|
| 플레이어 체력 | 100 |
| 플레이어 속도 | 6 |
| 좀비 체력 / 공격력 / 공격 간격 | 100 / 10 / 2초 |
| 좀비 속도 | 플레이어의 0.8배 (4.8) |

| 무기 | 데미지 | 탄창 | 발사 간격 | 재장전 | 획득 |
|---|---|---|---|---|---|
| 권총 | 25 | 6 | 0.7초 | 1.2초 | 기본 지급 |
| 샷건 | 25 × 4발 | 2 | 0.2초 | 1.0초 | 드롭 10% |
| 소총 | 20 | 40 | 0.1초 | 1.5초 | 드롭 10% |
| 저격총 | 100 | 1 (매 발 장전) | - | 1.5초 | 드롭 10% |

- 재장전 중에는 머리 위에 장전 바가 표시됩니다
- 좀비 처치 시 5% 확률로 체력 +10 아이템 드롭 (체력이 가득이면 줍지 않음)
- 드롭 아이템은 30초 뒤 사라짐 (마지막 5초 깜빡임)

## 웨이브
- 총 5웨이브, 웨이브당 30초
- 스폰 구역 2곳에서 각각 1초에 1마리씩
- 1웨이브 구역당 5마리(총 10), 웨이브마다 구역당 +5 → 5웨이브는 구역당 25마리(총 50)
- 마지막 웨이브의 좀비를 모두 잡으면 승리
- `WaveManager`의 `startNextWaveWhenCleared`를 켜면 다 잡았을 때 30초를 기다리지 않고 다음 웨이브 시작

## 수치 바꾸기
Play 중 Hierarchy에서 `GameRoot > Player`(PlayerWeapons의 weapons 배열), `GameRoot > WaveManager`를 선택하면 Inspector에서 바로 바꿔볼 수 있습니다.
영구적으로 바꾸려면 `WeaponData.cs`(무기), `Zombie.cs`(좀비/드롭 확률), `WaveManager.cs`(웨이브)의 기본값을 수정하세요.

## 파일
| 파일 | 역할 |
|---|---|
| GameBootstrap.cs | 맵·플레이어·카메라 자동 생성, 재시작 |
| MapLayout.cs | 맵 크기/벽/문/스폰 위치 데이터, 문 길찾기 |
| GameManager.cs | 게임 상태, HUD(체력·웨이브·무기·장전 바) |
| PlayerController.cs | 이동, 조준 |
| PlayerWeapons.cs | 무기 보유·교체·사격·재장전 |
| WeaponData.cs | 무기 수치 |
| Bullet.cs | 총알 |
| Zombie.cs | 좀비 AI, 공격, 보상 드롭 |
| Pickup.cs | 드롭 아이템 |
| SpawnZone.cs | 1/4 원 스폰 구역 |
| WaveManager.cs | 웨이브 진행 |
| Health.cs / CameraFollow.cs / GameInput.cs | 체력, 카메라, 입력 |
